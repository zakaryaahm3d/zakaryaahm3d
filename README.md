<h2 id="projects">✦ Projects</h2>

### EcoBite - Food Waste Management Platform (Microsoft Imagine Cup)
Full-stack donation platform with Azure auth + logistics tracking.

- Built a multi-role donation platform with role-based access control for five distinct user roles.
- Developed NGO and recycler dashboards enabling weekly distribution of 500+ meals across partner organizations.
- Integrated Azure AD B2C for authentication, Azure SQL for persistence, and Azure Maps for real-time logistics + rewards management; increased donation conversion by 30% via analytics and targeted UI improvements.
- Badge: <img src="https://img.shields.io/badge/Microsoft%20Imagine%20Cup-0ea5e9?style=for-the-badge&logo=microsoft&logoColor=white" />

---

### Magic Weather Bento
C++ low-latency HTTP + Dijkstra smart routing driven by weather severity.

- Engineered a low-latency HTTP server in C++ from scratch using Winsock2, handling raw TCP/IP connections and request parsing without external frameworks.
- Implemented Dijkstra's Algorithm for a smart routing engine, weighing graph edges by real-time weather severity and distance metrics.
- Optimized critical operations using priority queues for ranking severe weather alerts and hash maps for O(1) city data retrieval, reducing lookup latency.
- Badge: <img src="https://img.shields.io/badge/C%2B%2B%20Systems%20%26%20Algorithms-1f2937?style=for-the-badge&logo=cplusplus&logoColor=7aa2f7" />

---

### Arcade Simulator
Two games in one: Snake and Flappy Bird, powered by SFML.

- Designed and developed an interactive Arcade Simulator featuring two embedded games: Snake and Flappy Bird, using C++ and SFML.
- Implemented real-time graphics rendering, collision detection, and audio effects via the SFML multimedia library.
- Built modular OOP architecture with game state transitions, pause-resume functionality, and file I/O for persistent high score storage.
- Badge: <img src="https://img.shields.io/badge/SFML%20Arcade%20Lab-10b981?style=for-the-badge&logo=spring&logoColor=white" />

---

### Interactable Sudoku
CLI Sudoku with backtracking correction and validation.

- Developed a fully playable command-line Sudoku game in C++ with intuitive user interface and real-time interactivity.
- Implemented dynamic board generation, input validation, backtracking correction, and automated win condition detection.
- Structured the codebase with strict separation of concerns across UI, game logic, and validation layers for scalability and maintainability.
- Badge: <img src="https://img.shields.io/badge/Algorithms%20%26%20CLI%20UX-ef4444?style=for-the-badge&logo=terminal&logoColor=white" />
